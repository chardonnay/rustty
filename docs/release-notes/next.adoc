= RusTTY Draft Release Notes
:toc:

== Unreleased

=== Configuration

* `rustty` can now print a sample RusTTY configuration for schema review.
  xref:../changelogs/rustty.adoc#rustty-sample-config[Changelog entry]
* `rustty` can now show the default config path, initialize a sample config
  file, and validate an existing RusTTY config.
  xref:../changelogs/rustty.adoc#rustty-config-cli[Changelog entry]
* The RusTTY config layer now includes default-path resolution and validated
  file persistence helpers.
  xref:../../CHANGELOG.adoc#suite-config-cli[Changelog entry]
* RusTTY config validation now enforces unique session names so tool-level
  session lookup stays deterministic.
  xref:../../CHANGELOG.adoc#suite-rusplink-cli[Changelog entry]
* RusTTY sessions can now store reusable SSH `username` and `password_env`
  defaults, and config validation rejects empty auth-default values.
  xref:../../CHANGELOG.adoc#suite-session-auth-defaults[Changelog entry]
* RusTTY sessions can now also store reusable SSH `private_key_path` and
  `key_passphrase_env` defaults for public-key login flows.
  xref:../../CHANGELOG.adoc#suite-rusplink-public-key-auth[Changelog entry]
* RusTTY sessions can now also carry validated saved local port-forward
  definitions for `rusplink`.
  xref:../../CHANGELOG.adoc#suite-rusplink-local-forwarding[Changelog entry]

=== rusplink

* `rusplink` can now print the default config path and list validated RusTTY
  sessions from disk.
  xref:../changelogs/rusplink.adoc#rusplink-dry-run-cli[Changelog entry]
* `rusplink` can now resolve saved SSH sessions and direct SSH targets into a
  stable dry-run connection plan.
  xref:../changelogs/rusplink.adoc#rusplink-dry-run-cli[Changelog entry]
* `rusplink` can now execute remote SSH commands with password authentication
  sourced from an environment variable.
  xref:../changelogs/rusplink.adoc#rusplink-ssh-exec-transport[Changelog entry]
* `rusplink` can now consume saved session `username` and `password_env`
  defaults and surface them in session listings.
  xref:../changelogs/rusplink.adoc#rusplink-session-auth-defaults[Changelog entry]
* `rusplink` can now authenticate with OpenSSH private keys, optional
  passphrase indirection, and password fallback ordering.
  xref:../changelogs/rusplink.adoc#rusplink-public-key-auth[Changelog entry]
* `rusplink` can now open local TCP forwarding listeners from either
  `--local-forward` flags or saved RusTTY session rules.
  xref:../changelogs/rusplink.adoc#rusplink-local-forwarding[Changelog entry]
* `rusplink` can now resolve a default known-hosts path, verify exact stored
  host keys, persist first-seen keys for `accept_new`, and open interactive
  SSH shells with a remote PTY.
  xref:../changelogs/rusplink.adoc#rusplink-known-hosts-shell[Changelog entry]
* `ask` host-key policy remains conservative for unknown hosts and still does
  not offer an interactive trust prompt.
  xref:../changelogs/rusplink.adoc#rusplink-known-hosts-shell[Changelog entry]
