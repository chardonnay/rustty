= RusTTY Draft Release Notes
:toc:

== Unreleased

=== Configuration

* `rustty` can now print a sample RusTTY configuration for schema review.
  xref:../changelogs/rustty.adoc#rustty-sample-config[Changelog entry]
* `rustty` can now show the default config path, initialize a sample config
  file, and validate an existing RusTTY config.
  xref:../changelogs/rustty.adoc#rustty-config-cli[Changelog entry]
* The RusTTY config layer now includes default-path resolution and validated
  file persistence helpers.
  xref:../../CHANGELOG.adoc#suite-config-cli[Changelog entry]
* RusTTY config validation now enforces unique session names so tool-level
  session lookup stays deterministic.
  xref:../../CHANGELOG.adoc#suite-rusplink-cli[Changelog entry]

=== rusplink

* `rusplink` can now print the default config path and list validated RusTTY
  sessions from disk.
  xref:../changelogs/rusplink.adoc#rusplink-dry-run-cli[Changelog entry]
* `rusplink` can now resolve saved SSH sessions and direct SSH targets into a
  stable dry-run connection plan.
  xref:../changelogs/rusplink.adoc#rusplink-dry-run-cli[Changelog entry]

=== Developer workflow

* Contributor workflow, branch naming, and CODEOWNERS are now documented and
  enforced more strictly.
  xref:../../CHANGELOG.adoc#suite-config-foundation[Changelog entry]
