= RusTTY Draft Release Notes
:toc:

== Unreleased

=== Configuration

* `rustty` can now print a sample RusTTY configuration for schema review.
  xref:../changelogs/rustty.adoc#rustty-sample-config[Changelog entry]
* `rustty` can now show the default config path, initialize a sample config
  file, and validate an existing RusTTY config.
  xref:../changelogs/rustty.adoc#rustty-config-cli[Changelog entry]
* `rustty` can now show the default RusTTY `known_hosts` path and import exact
  OpenSSH-style host-key entries into RusTTY-managed storage, including
  dry-run reporting for migration review.
  xref:../changelogs/rustty.adoc#rustty-hostkey-import[Changelog entry]
* `rustty` can now also import PuTTY Windows registry exports and Unix
  `sshhostkeys` files into RusTTY-managed host-key storage, with UTF-16
  registry-export decoding and explicit skip reporting for unsupported keys.
  xref:../changelogs/rustty.adoc#rustty-hostkey-import[Changelog entry]
* The RusTTY config layer now includes default-path resolution and validated
  file persistence helpers.
  xref:../../CHANGELOG.adoc#suite-config-cli[Changelog entry]
* RusTTY config validation now enforces unique session names so tool-level
  session lookup stays deterministic.
  xref:../../CHANGELOG.adoc#suite-rusplink-cli[Changelog entry]
* RusTTY sessions can now store reusable SSH `username` and `password_env`
  defaults, and config validation rejects empty auth-default values.
  xref:../../CHANGELOG.adoc#suite-session-auth-defaults[Changelog entry]
* RusTTY sessions can now also store reusable SSH `private_key_path` and
  `key_passphrase_env` defaults for public-key login flows.
  xref:../../CHANGELOG.adoc#suite-rusplink-public-key-auth[Changelog entry]
* RusTTY sessions can now also carry reusable SSH `keyboard_interactive_env`
  defaults for scripted keyboard-interactive login flows.
  xref:../../CHANGELOG.adoc#suite-rusplink-keyboard-interactive-auth[Changelog entry]
* RusTTY now resolves a default SSH-agent socket path alongside
  `config.toml` and `known_hosts`.
  xref:../../CHANGELOG.adoc#suite-rusagent-agent-auth[Changelog entry]
* RusTTY now includes an explicit host-key migration helper for exact
  OpenSSH-style `known_hosts` entries, with reporting for skipped unsupported
  patterns.
  xref:../../CHANGELOG.adoc#suite-hostkey-import-migration[Changelog entry]
* RusTTY sessions can now also carry validated saved local port-forward
  definitions for `rusplink`.
  xref:../../CHANGELOG.adoc#suite-rusplink-local-forwarding[Changelog entry]
* RusTTY sessions can now also carry validated saved remote-forward
  definitions for `rusplink`.
  xref:../../CHANGELOG.adoc#suite-rusplink-remote-forwarding[Changelog entry]
* RusTTY sessions can now also carry validated saved dynamic-forward listener
  definitions for `rusplink`.
  xref:../../CHANGELOG.adoc#suite-rusplink-dynamic-forwarding[Changelog entry]

=== rusplink

* `rusplink` can now print the default config path and list validated RusTTY
  sessions from disk.
  xref:../changelogs/rusplink.adoc#rusplink-dry-run-cli[Changelog entry]
* `rusplink` can now resolve saved SSH sessions and direct SSH targets into a
  stable dry-run connection plan.
  xref:../changelogs/rusplink.adoc#rusplink-dry-run-cli[Changelog entry]
* `rusplink` can now execute remote SSH commands with password authentication
  sourced from an environment variable.
  xref:../changelogs/rusplink.adoc#rusplink-ssh-exec-transport[Changelog entry]
* `rusplink` can now consume saved session `username` and `password_env`
  defaults and surface them in session listings.
  xref:../changelogs/rusplink.adoc#rusplink-session-auth-defaults[Changelog entry]
* `rusplink` can now authenticate with OpenSSH private keys, optional
  passphrase indirection, and password fallback ordering.
  xref:../changelogs/rusplink.adoc#rusplink-public-key-auth[Changelog entry]
* `rusplink` now documents and regression-tests PuTTY `PPK` private-key input
  anywhere `--private-key PATH` or a saved session key path is used.
  xref:../changelogs/rusplink.adoc#rusplink-putty-ppk-auth[Changelog entry]
* `rusplink` can now authenticate with environment-driven SSH
  keyboard-interactive responses and include that auth source in its ordered
  fallback chain.
  xref:../changelogs/rusplink.adoc#rusplink-keyboard-interactive-auth[Changelog entry]
* `rusplink` can now authenticate through a running SSH agent via
  `--agent` or `--agent-socket PATH`.
  xref:../changelogs/rusplink.adoc#rusplink-agent-auth[Changelog entry]
* `rusplink` can now open local TCP forwarding listeners from either
  `--local-forward` flags or saved RusTTY session rules.
  xref:../changelogs/rusplink.adoc#rusplink-local-forwarding[Changelog entry]
* `rusplink` can now open remote TCP forwarding listeners from either
  `--remote-forward` flags or saved RusTTY session rules.
  xref:../changelogs/rusplink.adoc#rusplink-remote-forwarding[Changelog entry]
* `rusplink` can now open local SOCKS5 listeners from either
  `--dynamic-forward` flags or saved RusTTY session rules.
  xref:../changelogs/rusplink.adoc#rusplink-dynamic-forwarding[Changelog entry]
* `rusplink` can now resolve a default known-hosts path, verify exact stored
  host keys, persist first-seen keys for `accept_new`, and open interactive
  SSH shells with a remote PTY.
  xref:../changelogs/rusplink.adoc#rusplink-known-hosts-shell[Changelog entry]
* `rusplink` now offers an interactive `ask` host-key prompt for unknown
  servers, with SHA-256 fingerprint display, store-or-once trust decisions,
  and clearer mismatch diagnostics for stale `known_hosts` entries.
  xref:../changelogs/rusplink.adoc#rusplink-hostkey-prompts[Changelog entry]

=== rusagent

* `rusagent` can now serve a Unix-domain SSH-agent socket, preload OpenSSH
  identities, add identities to a running agent, and list loaded public keys.
  xref:../changelogs/rusagent.adoc#rusagent-socket-service[Changelog entry]
* `rusagent` now documents and regression-tests PuTTY `PPK` private-key input
  for `--identity PATH` and `--add-identity PATH`.
  xref:../changelogs/rusagent.adoc#rusagent-putty-ppk-input[Changelog entry]

=== rusttygen

* `rusttygen` now provides a real bootstrap CLI for inspecting OpenSSH or
  PuTTY `PPK` private keys and converting them into OpenSSH outputs.
  xref:../changelogs/rusttygen.adoc#rusttygen-ppk-bootstrap[Changelog entry]
