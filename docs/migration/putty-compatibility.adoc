= PuTTY Compatibility
:toc:

RusTTY aims for behavioral compatibility with the PuTTY suite where that helps
users migrate, but it does not promise a file-for-file or UI-for-UI clone.

== Compatibility Priorities

* Session import from existing PuTTY data.
* Host-key migration from existing OpenSSH-style trust stores.
* Key import and export for PuTTY PPK and OpenSSH formats.
* Familiar tool boundaries and protocol coverage.
* Clear documentation for intentional differences.

== Intentional Differences

* RusTTY uses its own repository, branch workflow, and release process.
* RusTTY stores new configuration in a native RusTTY format rather than
  continuing to treat PuTTY storage as the write target.
* Internal structure is Rust-native and workspace-oriented instead of mirroring
  PuTTY's C code layout.
* Host-key migration currently targets OpenSSH-style `known_hosts` files
  before any future PuTTY-registry import path.

== Tool Mapping

* `putty` -> `rustty`
* `plink` -> `rusplink`
* `pscp` -> `ruscp`
* `psftp` -> `rusftp`
* `pageant` -> `rusagent`
* `puttygen` -> `rusttygen`

See the per-tool manuals for deeper migration notes.
