= rusagent Changelog

== Unreleased

[#rusagent-putty-ppk-input]
=== PuTTY PPK identity loading

* Documented and regression-tested `rusagent` support for loading PuTTY `PPK`
  private keys through `--identity PATH` and `--add-identity PATH`.
* Kept encrypted `PPK` support aligned with existing passphrase-indirection
  through `--passphrase-env ENV`.

[#rusagent-socket-service]
=== Socket service and identity loading

* Added `--show-default-socket-path`, `--serve`, `--list`, and
  `--add-identity` so `rusagent` can act as a real SSH-agent bootstrap tool.
* Added OpenSSH private-key loading with optional passphrase indirection and
  optional SSH-agent lifetime constraints.
* Added Unix-domain socket serving and identity queries so bootstrap
  `rusplink` sessions can authenticate through a shared agent process.

[#rusagent-bootstrap-repo]
=== Bootstrap repository

* Added the `rusagent` binary scaffold.
* Added the `rusagent` manual and documented its role as the Pageant
  replacement.
