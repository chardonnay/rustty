= rusplink Changelog

== Unreleased

[#rusplink-keyboard-interactive-auth]
=== Keyboard-interactive authentication

* Added `--keyboard-interactive-env ENV` so `rusplink` can feed newline-
  separated prompt responses into SSH keyboard-interactive login flows.
* Added ordered auth resolution so `rusplink` now prefers public-key auth,
  then keyboard-interactive auth, then password authentication.
* Extended dry-run output and session listings to expose saved
  `keyboard_interactive_env` defaults and active auth ordering.

[#rusplink-remote-forwarding]
=== Remote port forwarding

* Added `--remote-forward SOURCE=TARGET` so `rusplink` can request remote TCP
  listeners over the active SSH connection.
* Added SSH `tcpip-forward` setup plus bridging for incoming
  `forwarded-tcpip` channels back to client-side local targets.
* Added dry-run and saved-session visibility for reusable remote-forward
  rules.

[#rusplink-dynamic-forwarding]
=== Dynamic SOCKS forwarding

* Added `--dynamic-forward [HOST:]PORT` so `rusplink` can open local SOCKS5
  listeners on the active SSH connection.
* Added SOCKS5 `CONNECT` handling for IPv4, IPv6, and DNS-style destination
  targets over SSH `direct-tcpip`.
* Added dry-run and saved-session visibility for reusable dynamic-forward
  listeners.

[#rusplink-local-forwarding]
=== Local port forwarding

* Added `--local-forward SOURCE=TARGET` so `rusplink` can open local TCP
  listeners that tunnel through the active SSH connection.
* Added dry-run and session-plan visibility for resolved forwarding rules.
* Added support for loading saved RusTTY session forwarding rules and merging
  them with CLI-supplied rules for the current invocation.

[#rusplink-public-key-auth]
=== Public-key authentication

* Added `--private-key` and `--key-passphrase-env` so `rusplink` can use
  OpenSSH private keys for both dry-run planning and live SSH transport.
* Added ordered auth resolution so `rusplink` prefers public-key auth first
  and can keep password authentication as an explicit fallback.
* Extended dry-run output and session listings to expose saved private-key and
  passphrase-indirection defaults.

[#rusplink-session-auth-defaults]
=== Session auth defaults

* Added support for stored SSH `username` and `password_env` defaults in
  RusTTY-backed sessions consumed by `rusplink`.
* Made `--username` and `--password-env` override those saved session values
  explicitly instead of forcing callers to repeat the same data every time.
* Extended session listing output so reusable auth defaults are visible in the
  line-oriented bootstrap table.

[#rusplink-known-hosts-shell]
=== Known-host persistence and interactive shells

* Added `--show-default-known-hosts-path` and `--known-hosts PATH` so
  `rusplink` can inspect and override the RusTTY-managed host-key store.
* Added exact-match OpenSSH-style known-host lookup and append-only persistence
  for `accept_new` SSH sessions.
* Added interactive SSH shell support with remote PTY allocation when no
  remote command is supplied.
* Continued to keep `ask` conservative for unknown hosts: stored host keys are
  accepted, but interactive trust prompts remain intentionally unimplemented.

[#rusplink-ssh-exec-transport]
=== SSH exec transport

* Added a reusable `rustty-transport` crate and wired `rusplink` to execute
  remote SSH `exec` requests when a command is supplied after `--`.
* Added `--username`, `--password-env`, and `--unsafe-accept-host-key` for the
  current bootstrap transport flow.
* Limited live transport to password authentication in the current bootstrap
  slice.

[#rusplink-dry-run-cli]
=== Session lookup and dry-run planning

* Added `--show-default-config-path` and `--list-sessions` to inspect
  RusTTY-backed `rusplink` configuration.
* Added `--session NAME --dry-run` to resolve saved SSH sessions into a stable,
  line-oriented execution plan.
* Added direct-target dry-run planning for `host`, `user@host`, `host:port`,
  and bracketed IPv6 target forms.
* Rejected non-SSH saved sessions at `rusplink` resolution time and tightened
  config validation so stored session names remain unique.

[#rusplink-bootstrap-repo]
=== Bootstrap repository

* Added the `rusplink` binary scaffold.
* Added the `rusplink` manual and documented its role as the Plink replacement.
