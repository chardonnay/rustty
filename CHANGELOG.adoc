= RusTTY Changelog
:toc:

This file tracks suite-level milestones. Tool-specific details live under
`docs/changelogs/`.

== Unreleased

[#suite-rustty-gui-launcher]
=== rustty GUI launcher

* Replaced the `rustty` placeholder output with a native desktop launcher
  backed by the shared `rustty-ui` crate.
* Added a config-aware session browser, selected-session inspector, and
  quick-connect planning surface so the GUI can already review RusTTY config
  and PuTTY migration results before the embedded terminal lands.
* Added GUI-visible diagnostics and a tool catalog for documentation and
  release-tracking paths.

[#suite-rustty-gui-command-runner]
=== rustty launcher command runner

* Added a launcher-side SSH command runner for saved SSH sessions, including
  GUI host-key confirmation and captured command output.

[#suite-rustty-terminal-window]
=== rustty terminal window

* Added the first dedicated saved-session terminal window to `rustty`.
* Moved SSH command execution history, host-key prompts, and captured output
  into that session window so the launcher can stay focused on browsing and
  selection.
* Added a transcript-style presentation for queued commands, stdout, stderr,
  warnings, and completion summaries inside the GUI.

[#suite-rustty-interactive-shell]
=== rustty interactive shell

* Added the first live SSH shell inside the `rustty` terminal window.
* Added GUI-side PTY input forwarding, resize propagation, and remote shell
  exit reporting without leaving the desktop client.
* Added a streaming shell buffer with lightweight ANSI stripping and
  backspace handling so basic interactive shells render usefully before full
  terminal emulation lands.

[#suite-config-foundation]
=== Configuration foundation

* Added a dedicated RusTTY configuration crate with TOML serialization and
  import provenance support.
* Added contributor workflow files, CODEOWNERS, and issue-template guidance.
* Added branch-name enforcement and AsciiDoc policy checks to repository
  automation.

[#suite-config-cli]
=== Config CLI workflows

* Added default-path resolution, file initialization, saving, loading, and
  validation helpers for RusTTY config files.
* Added `rustty` CLI entry points for printing the default config path,
  initializing sample config files, and validating stored config.

[#suite-rusplink-cli]
=== rusplink session planning

* Added unique session-name validation so saved config lookups stay stable
  across CLI tools.
* Added `rusplink` commands for default-path discovery, session listing, and
  SSH dry-run planning from either saved sessions or direct targets.

[#suite-session-auth-defaults]
=== Session auth defaults

* Added reusable per-session SSH `username` and `password_env` fields to the
  RusTTY config schema and bootstrap sample config.
* Tightened config validation so empty stored auth-default values are rejected
  before runtime.
* Updated `rusplink` to consume and surface those saved auth defaults in
  session listings and dry-run planning.

[#suite-rusplink-public-key-auth]
=== rusplink public-key authentication

* Added reusable per-session SSH `private_key_path` and `key_passphrase_env`
  fields to the RusTTY config schema.
* Added OpenSSH private-key authentication to `rusplink`, with optional
  passphrase indirection and password fallback ordering.
* Extended `rusplink` dry-run and session-listing output so auth preference
  order and saved key defaults are visible in script-friendly output.

[#suite-rusplink-keyboard-interactive-auth]
=== rusplink keyboard-interactive authentication

* Added reusable per-session SSH `keyboard_interactive_env` fields to the
  RusTTY config schema.
* Added environment-driven keyboard-interactive authentication to `rusplink`,
  using newline-separated prompt responses resolved at execution time.
* Extended `rusplink` dry-run and session-listing output so
  keyboard-interactive defaults and auth ordering are visible in
  script-friendly output.

[#suite-rusagent-agent-auth]
=== rusagent and SSH-agent authentication

* Added RusTTY default-path resolution for an SSH-agent socket alongside
  `config.toml` and `known_hosts`.
* Added a bootstrap `rusagent` CLI that can serve a Unix-domain agent socket,
  preload OpenSSH identities, add identities to a running agent, and list
  exposed public keys.
* Added `rusplink` support for ordered SSH-agent authentication via
  `--agent` or `--agent-socket`, between direct key auth and
  keyboard-interactive fallback.

[#suite-putty-ppk-interoperability]
=== PuTTY PPK interoperability

* Made PuTTY `PPK` private-key input an explicit, regression-tested bootstrap
  path for both `rusplink` and `rusagent`.
* Added a real `rusttygen` bootstrap CLI for private-key inspection and
  one-way `PPK` to OpenSSH conversion.
* Added repository-local `PPK` compatibility fixtures with attribution notes
  so future key-format changes stay testable.

[#suite-rusplink-local-forwarding]
=== rusplink local port forwarding

* Added reusable saved local port-forward rules to the RusTTY session flow.
* Added `rusplink` support for CLI-defined and session-defined local TCP
  forwarding through SSH `direct-tcpip`.
* Tightened config validation so empty saved port-forward source or target
  fields are rejected before runtime.

[#suite-rusplink-dynamic-forwarding]
=== rusplink dynamic forwarding

* Added reusable saved dynamic-forward listener rules to the RusTTY session
  flow.
* Added `rusplink` support for CLI-defined and session-defined SOCKS5
  listeners that tunnel `CONNECT` traffic through SSH `direct-tcpip`.
* Tightened config validation so empty saved dynamic-forward listener fields
  are rejected before runtime.

[#suite-rusplink-remote-forwarding]
=== rusplink remote port forwarding

* Added reusable saved remote-forward rules to the RusTTY session flow.
* Added `rusplink` support for CLI-defined and session-defined SSH
  `tcpip-forward` listeners that bridge incoming remote connections back to
  client-side local targets.
* Tightened config validation so empty saved remote-forward source or target
  fields are rejected before runtime.

[#suite-rusplink-ssh-transport]
=== rusplink SSH transport

* Added a reusable `rustty-transport` crate for SSH exec requests.
* Added bootstrap `rusplink` transport support for password-authenticated SSH
  command execution with explicit, unsafe host-key override handling.

[#suite-rusplink-known-hosts-shell]
=== rusplink host keys and shells

* Added a RusTTY-managed OpenSSH-style known-host store with default-path
  resolution and append-only persistence for exact host or `host:port`
  entries.
* Added `rusplink` host-key verification against stored known-host entries and
  automatic persistence for `accept_new` sessions.
* Added interactive SSH shell support with remote PTY allocation when
  `rusplink` runs without a remote command.

[#suite-rusplink-hostkey-prompts]
=== rusplink host-key prompts

* Added an interactive `ask` host-key flow that probes unknown server keys,
  prints their SHA-256 fingerprints, and lets operators store trust, continue
  once, or cancel.
* Pinned prompted `ask` sessions to the probed server key for the real SSH
  connection so the verified host key cannot change silently between prompt
  and login.
* Improved stale-key mismatch diagnostics so RusTTY now points operators at
  the exact `known_hosts` file that needs review.

[#suite-hostkey-import-migration]
=== Host-key import migration

* Added an explicit `rustty` migration helper for importing exact
  OpenSSH-style `known_hosts` entries into RusTTY-managed host-key storage.
* Added dry-run reporting and per-category skip counts so host-key migration
  remains reviewable when source files contain markers, hashed hosts,
  wildcards, or negations.
* Added PuTTY host-key import from Windows `.reg` exports and Unix
  `sshhostkeys` files, including UTF-16 registry-export decoding and
  explicit skip reporting for unsupported key types.
* Updated the migration documentation to describe the current host-key import
  boundary: OpenSSH `known_hosts` plus file-based PuTTY exports, but not live
  Windows registry reads.

[#suite-session-import-migration]
=== Session import migration

* Added an explicit `rustty` migration helper for importing PuTTY sessions
  from Windows `.reg` exports, Unix `sessions/` directories, and single Unix
  session files into RusTTY config storage.
* Added conflict-aware merge reporting so identical sessions are recognized,
  conflicting names are skipped, and dry-run imports remain reviewable.
* Added lossy-translation notes for PuTTY settings that are not yet modeled in
  RusTTY, including proxy settings, `RemoteCommand`, and selected SSH or
  serial preferences.

=== Repository bootstrap

* Established the RusTTY workspace, tool map, and shared branch policy.
* Added extensive AsciiDoc documentation for architecture, migration,
  licensing, tools, and release management.
* Added per-tool changelogs and release-note drafts intended to feed future
  build and release automation.
