= RusTTY
:toc:
:toclevels: 2

RusTTY is a Rust-first reimplementation plan for the PuTTY tool suite.
The repository starts with a documented bootstrap workspace so every future
feature branch inherits the same rules for branching, documentation, release
discipline, and legal attribution.

== Project Goals

* Rebuild the PuTTY user experience in Rust with a shared core and compact,
  separate binaries.
* Keep compatibility import paths for PuTTY sessions and key material while
  moving RusTTY to its own storage model.
* Treat documentation, changelogs, and release notes as first-class build
  inputs instead of post-release cleanup.
* Never work directly on `main`; all changes go through named branches.

== Tool Mapping

[cols="1,1,3",options="header"]
|===
| RusTTY tool | PuTTY counterpart | Current role

| `rustty`
| `putty`
| Cross-platform GUI terminal and session launcher.

| `rusplink`
| `plink`
| Command-line SSH and remote execution client.

| `ruscp`
| `pscp`
| Secure copy client for scripted and interactive transfers.

| `rusftp`
| `psftp`
| SFTP-oriented file transfer client.

| `rusagent`
| `pageant`
| SSH authentication agent and key broker.

| `rusttygen`
| `puttygen`
| Key generation, conversion, and inspection tool.
|===

== Repository Workflow

The branch model is documented in
xref:docs/architecture/repository-workflow.adoc[Repository Workflow].
In short:

* `main` is the protected integration branch.
* The initial scaffold lives on `chore/bootstrap-repo`.
* Every behavior change must ship with matching docs, changelog entries, and
  draft release-note updates.

== Bootstrap Status

The workspace currently provides:

* a Rust workspace with shared core, transport, and UI crates,
* a config bootstrap flow in `rustty`, including sample session auth defaults,
* a session-aware `rusplink` CLI with dry-run planning, bootstrap SSH exec
  transport, public-key and password authentication, known-host persistence,
  and interactive shell support,
* placeholder binaries for the remaining planned tools,
* an `xtask` utility that verifies documentation and release-note link
  integrity, and
* complete AsciiDoc manuals, migration notes, changelogs, and release-note
  scaffolding.

== Development Commands

[source,shell]
----
cargo fmt --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo run -p xtask -- ci
cargo run -p rustty -- --print-sample-config
cargo run -p rustty -- --show-default-config-path
cargo run -p rustty -- --init-config
cargo run -p rustty -- --validate-config
cargo run -p rusplink -- --list-sessions
cargo run -p rusplink -- --show-default-known-hosts-path
cargo run -p rusplink -- --session example-ssh --dry-run -- hostname
cargo run -p rusplink -- example.com --known-hosts /tmp/rustty-known_hosts --dry-run -- uptime
RUSTTY_SSH_PASSWORD=secret cargo run -p rusplink -- ops@example.com --unsafe-accept-host-key -- uptime
cargo run -p rusplink -- ops@example.com --private-key ~/.ssh/id_ed25519 --dry-run
----
