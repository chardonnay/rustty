= rustty Changelog

== Unreleased

[#rustty-gui-launcher]
=== Native GUI launcher

* Replaced the stdout placeholder flow with a native `rustty` desktop window.
* Added a saved-session browser with search, import-provenance display, and
  selected-session detail panels for auth defaults, forwarding, and host-key
  policy.
* Added a quick-connect draft surface that builds operator-facing launch
  previews while the embedded terminal window is still pending.
* Added launcher-side diagnostics and tool-catalog panels so config paths,
  manuals, and release-tracking artifacts are visible directly in the GUI.

[#rustty-hostkey-import]
=== Host-key import helpers

* Added `--show-default-known-hosts-path` so the `rustty` bootstrap CLI can
  report RusTTY's managed host-key store location.
* Added `--import-known-hosts SOURCE [--known-hosts PATH] [--dry-run]` so
  exact OpenSSH-style `known_hosts` entries can be migrated into RusTTY
  storage with an explicit summary of imported and skipped patterns.
* Added `--import-putty-host-keys SOURCE [--known-hosts PATH] [--dry-run]`
  so PuTTY Windows registry exports and Unix `sshhostkeys` files can be
  migrated into RusTTY storage with explicit skip reporting.
* Added dedicated migration documentation for host-key import boundaries and
  current compatibility limits.

[#rustty-session-import]
=== PuTTY session import helpers

* Added `--import-putty-sessions SOURCE [--config PATH] [--dry-run]` so
  PuTTY Windows `.reg` exports, Unix `sessions/` directories, and single Unix
  session files can be merged into RusTTY config storage.
* Added conflict-aware merge reporting so identical sessions are recognized,
  conflicting names are skipped, and dry runs remain reviewable.
* Added dedicated migration documentation for supported session fields,
  current translation limits, and lossy-import notes.

[#rustty-session-auth-defaults]
=== Session auth defaults in sample config

* Updated the bootstrap sample config to demonstrate per-session SSH
  `username` and `password_env` values.
* Tightened config validation so empty stored usernames and empty
  `password_env` values are rejected before later runtime use.

[#rustty-sample-config]
=== Sample config output

* Added `--print-sample-config` to expose the current RusTTY TOML schema from
  the `rustty` bootstrap binary.

[#rustty-config-cli]
=== Config path and validation commands

* Added `--show-default-config-path` to print RusTTY's platform-resolved config
  location.
* Added `--init-config` to create a sample config file without overwriting a
  valid existing file.
* Added `--validate-config` to parse and validate a RusTTY config file before
  later runtime use.

[#rustty-bootstrap-repo]
=== Bootstrap repository

* Added the `rustty` binary scaffold.
* Added the `rustty` manual and documented its role as the PuTTY replacement.
