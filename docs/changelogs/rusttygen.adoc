= rusttygen Changelog

== Unreleased

[#rusttygen-ppk-bootstrap]
=== PPK inspection and OpenSSH conversion

* Replaced the `rusttygen` placeholder binary with a real bootstrap CLI.
* Added `--inspect PATH` for line-oriented metadata on OpenSSH and PuTTY `PPK`
  private keys.
* Added `--convert PATH --output PATH` with optional `--public-output PATH`
  so PuTTY `PPK` keys can be migrated into OpenSSH private/public key files.

[#rusttygen-bootstrap-repo]
=== Bootstrap repository

* Added the `rusttygen` binary scaffold.
* Added the `rusttygen` manual and documented its role as the PuTTYgen
  replacement.
