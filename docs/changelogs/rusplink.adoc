= rusplink Changelog

== Unreleased

[#rusplink-ssh-exec-transport]
=== SSH exec transport

* Added a reusable `rustty-transport` crate and wired `rusplink` to execute
  remote SSH `exec` requests when a command is supplied after `--`.
* Added `--username`, `--password-env`, and `--unsafe-accept-host-key` for the
  current bootstrap transport flow.
* Limited live transport to password authentication and remote command
  execution for now; interactive shells and known-host persistence remain
  intentionally unimplemented.

[#rusplink-dry-run-cli]
=== Session lookup and dry-run planning

* Added `--show-default-config-path` and `--list-sessions` to inspect
  RusTTY-backed `rusplink` configuration.
* Added `--session NAME --dry-run` to resolve saved SSH sessions into a stable,
  line-oriented execution plan.
* Added direct-target dry-run planning for `host`, `user@host`, `host:port`,
  and bracketed IPv6 target forms.
* Rejected non-SSH saved sessions at `rusplink` resolution time and tightened
  config validation so stored session names remain unique.

[#rusplink-bootstrap-repo]
=== Bootstrap repository

* Added the `rusplink` binary scaffold.
* Added the `rusplink` manual and documented its role as the Plink replacement.
